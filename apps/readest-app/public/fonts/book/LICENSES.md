# Book fonts

Bundled so that reading works offline. All are free software under the SIL Open Font License 1.1
(https://openfontlicense.org), packaged by Fontsource (https://fontsource.org); each family's
copyright holders and licence text are in its Fontsource package.

EB Garamond, Libre Baskerville, Libre Caslon Text, Gelasio, Source Serif 4, Crimson Pro, Lora,
Spectral, Cardo, Alegreya, Noto Serif, Playfair Display, Cormorant Garamond, Newsreader, Charis SIL,
Gentium Book Plus, Zilla Slab, Atkinson Hyperlegible, OpenDyslexic, Lato, Montserrat, Jost, Lexend,
Nunito Sans, Source Sans 3, Libre Franklin, Arimo.
